# pdf-red-to-black

Μετατρέπει τα **κόκκινα** στοιχεία ενός PDF σε **μαύρα**.

Φτιάχτηκε για τα 11 PDF του ASEP «Μητρώο Θεμάτων Γνώσεων»
(<https://info.asep.gr/mitroo-thematon-gnoseon>), όπου η **σωστή απάντηση κάθε
ερώτησης είναι τυπωμένη με κόκκινο**. Το εργαλείο κάνει τα πάντα μαύρα, ώστε να
μη φαίνεται ποια απάντηση είναι η σωστή και να μπορείς να εξασκείσαι «στα τυφλά».

## Τι κάνει

Ξαναγράφει τα content streams κάθε σελίδας: όποιος τελεστής χρώματος επιλέγει
κόκκινο (RGB, CMYK ή 3-συστατικών `scn`) αντικαθίσταται με μαύρο. Έτσι γίνεται
μαύρο **και το κόκκινο κείμενο και οι κόκκινες γραμμές/σχήματα**, ενώ όλο το
υπόλοιπο περιεχόμενο μένει ακέραιο. Στο τέλος αναφέρει αν έμεινε κάποιο κόκκινο
κείμενο που δεν προσεγγίστηκε (σπάνιο — π.χ. χρώμα ορισμένο μέσω named colorspace).

## Απαιτήσεις

```bash
pip install pymupdf
```

## Χρήση

```bash
# Α) Έχεις ήδη κατεβάσει τα PDF σε έναν φάκελο:
python3 red_to_black.py --in ./pdfs --out ./pdfs_black

# Β) Μεμονωμένα αρχεία:
python3 red_to_black.py enotita1.pdf enotita2.pdf --out ./out

# Γ) Κατέβασμα των 11 PDF από τη σελίδα του ASEP και μετά επεξεργασία
#    (χρειάζεται πρόσβαση στο info.asep.gr):
python3 red_to_black.py --fetch --out ./asep_black
```

Τα επεξεργασμένα PDF γράφονται στον φάκελο `--out` με τα ίδια ονόματα.

## Σημείωση

Το script δοκιμάστηκε σε PDF με κόκκινο κείμενο, κόκκινη γραμμή και κόκκινο
γέμισμα (RGB) — και τα τρία έγιναν σωστά μαύρα. Αν κάποιο PDF του ASEP ορίζει το
κόκκινο με άλλο μοντέλο χρώματος, το εργαλείο θα σε ειδοποιήσει στο τέλος για να
το ελέγξεις χειροκίνητα.
